## Cómo ejecutar un ejercicio

Cada carpeta es un proyecto Maven independiente:

```bash
cd ej01-veterinaria
mvn clean javafx:run
```

También puedes abrir la carpeta del ejercicio directamente en IntelliJ IDEA y esperar a que Maven sincronice. Cada proyecto incluye su propio `README.md` con los detalles.
